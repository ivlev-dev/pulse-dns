Локальная правка нагрузчика для resolver-фазы (репозиторий не менялся).

Причина: штатный pulse-loadgen собирает запросы с RD=0. BIND, Unbound и
PowerDNS Recursor отвечают на такие запросы REFUSED (проверено relay-снимком:
Unbound -> RCODE 5), поэтому все ответы учитывались как invalid.

Правка — одна строка в копии crates/pulse-loadgen/src/wire.rs:

--- a/crates/pulse-loadgen/src/wire.rs
+++ b/crates/pulse-loadgen/src/wire.rs
@@ -94,6 +94,9 @@ fn build_packet(class: Class, name: &str, qtype: Rtype, dnssec_do: bool) -> Resu
     let name = Name::parse(name).map_err(|error| format!("query name {name:?}: {error}"))?;
     let mut message = Message::query(0, Question::new(name.clone(), qtype, Rclass::IN));
+    // Resolver clients set RD=1 (RFC 1035). The shipped loadgen leaves it 0,
+    // which BIND/Unbound/PowerDNS recursors answer with REFUSED.
+    message.set_flags(message.flags().with_rd(true));
     if dnssec_do {
         message.set_edns(Some(Edns::new(1232).with_dnssec_ok(true)));
     }
