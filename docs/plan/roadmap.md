# Roadmap

| Этап | Описание |
|---|---|
| M0 | Фундамент и спецификации — ✅ выполнено |
| M1 | pulse-zonefile: спецификация + прототип — 🔄 в работе |
| M2 | pulse-dns: wire-формат |
| M3 | pulsed: авторитетный сервер (UDP/TCP, primary/secondary, REST) |
| M4 | pulseresolved: рекурсия, кеш, ad-block, overrides |
| M5 | DNSSEC, затем DNSCrypt |
| M6 | DoT/DoH, observability, нагрузочные тесты |

Примечание: v1 = релиз после M0–M6; DNSSEC входит в v1 (реализация — M5, готовность формата — M1); DNSCrypt — после DNSSEC.
